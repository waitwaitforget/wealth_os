## 2. 页面路由

| 路由 | 页面 | 功能 |
|------|------|------|
| `/` | Dashboard | 总览驾驶舱 |
| `/portfolio` | 组合详情 | 持仓明细、权重趋势、交易历史 |
| `/factors` | 因子看板 | 27 因子信号矩阵、历史分位 |
| `/risk` | 风险中心 | 风险分解、压力测试、VaR 曲线 |
| `/decisions` | 决策日志 | 历史决策列表、审批流程 |
| `/backtest` | 回测对比 | 策略对比 (B0-B6)、基准归因 |
| `/data` | 数据健康 | 数据源状态、质量报告、版本 |
| `/settings` | 策略配置 | 参数调整、约束设置 |

## 3. FinTech 视觉风格

### 配色方案
```
Background:  #0a0e17 (深蓝黑)
Card:        #111827 (卡片背景)
Border:      #1e293b (边框)
Primary:     #3b82f6 (蓝，用于上涨/买入)
Secondary:   #8b5cf6 (紫，用于强调)
Danger:      #ef4444 (红，用于下跌/卖出/警告)
Success:     #22c55e (绿，用于通过)
Warning:     #f59e0b (黄，用于警告)
Text:        #e2e8f0 (主文本)
TextMuted:   #64748b (次要文本)
```

### 字体
```
Headings: Inter / SF Pro Display
Body:     Inter / SF Pro Text
Numbers:  JetBrains Mono / SF Mono (表格数字用等宽)
```

### 卡片风格
```
圆角 12px, 半透明边框, 微妙阴影
hover 时微升 + 边框亮度提升
```

## 4. 关键组件设计

### 4.1 Top Bar（顶部栏）
```
┌────────────────────────────────────────────────────────────┐
│  💰 ¥ 2,817,622                                    ⚡ LIVE │
│  +4.35% YTD   │  策略: Production   │  数据: Healthy   │
└────────────────────────────────────────────────────────────┘
```
- 总资产大字，涨跌颜色标识
- 策略状态指示灯 (绿色=Production, 黄色=Shadow, 红色=Suspended)
- 数据健康快捷状态

### 4.2 资产配置饼图
- 双层环形：外层 = 资产类别(Sleeve)，内层 = 具体标的
- Hover 显示：名称、权重、市值、当日涨跌
- 中心显示总规模

### 4.3 风险仪表盘
```
┌─────────────────────────────┐
│  风险指标                    │
│                             │
│  波动率   7.74%   ████░░     │
│  Sharpe   0.720   ███░░░     │
│  Max DD  -14.1%   ██░░░░     │
│  CDaR    -11.6%   ██░░░░     │
│                             │
│  回撤状态: NORMAL ●          │
│  风险倍数: ×1.00             │
└─────────────────────────────┘
```
- 进度条式指标展示
- 颜色编码：绿(低风险) → 黄 → 红(高风险)
- 回撤状态指示灯

### 4.4 净值曲线
- 面积图：NAV 历史 vs Benchmark
- X 轴时间，Y 轴对数净值
- 标注调仓事件点（竖虚线）
- 标注最大回撤区间（红色阴影）

### 4.5 因子热力图
```
         Value  Trend   Risk  Combined
CSI300    +1.2   -0.8   +0.3     +0.7
HSI       +0.8   +0.5   -0.1     +1.2
SP500     -0.5   +2.1   +0.5     +2.1
NDX100    +0.3   +1.9   +0.2     +2.4
GOLD      +0.3   +0.3   -0.2     +0.4
```
- 热力图矩阵：行=资产，列=因子类别
- 颜色：绿(看多) → 白(中性) → 红(看空)
- 可展开看单因子详情

### 4.6 决策卡片
```
┌──────────────────────────────────────────┐
│  📋 2024-09-15  REBALANCE (6 trades)    │
│                                          │
│  买入 SP500        22% → 28%  +6.0%     │
│        原因: Trend +2.1, 权重漂移8%      │
│        成本估算: 0.6 bps                 │
│                                          │
│  卖出 CSI300       18% → 20%  -0.0%     │
│        原因: Trend -0.8, 约束限制        │
│        状态: ⏳ Pending                  │
│        审批: [Approve] [Reject]          │
└──────────────────────────────────────────┘
```

## 5. 移动端适配

- 单列布局（左右合并为上下）
- Top bar 压缩为顶部固定
- 底部 tab bar 导航
- 卡片可折叠展开
- 手势滑动查看图表

## 6. 技术栈建议

| 层 | 技术 |
|----|------|
| 前端 | Next.js 14 + React 18 + TypeScript |
| 样式 | Tailwind CSS + shadcn/ui |
| 图表 | Recharts / ECharts |
| API | FastAPI (Python, 已规划) |
| 部署 | Vercel (前端) + Docker (后端) |
| 状态 | React Query (服务端状态) |

```text

GET  /api/v1/factors/signals          # 当前因子信号矩阵
GET  /api/v1/risk/metrics             # 风险指标
GET  /api/v1/decisions/recent         # 最近决策

GET  /api/v1/data/health              # 数据健康状态
GET  /api/v1/backtest/compare         # 策略对比结果
```
