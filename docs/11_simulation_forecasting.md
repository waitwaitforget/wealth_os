# 11. Simulation & Forecasting 设计

## 1. 目标

模拟系统用于理解不确定性，而不是制造精确预测。输出必须是区间、概率和情景，不应给单一确定收益数字。

## 2. 时间尺度

### 1 年以内

重点展示：

- 波动率和回撤分布；
- 亏损概率；
- 压力情景；
- 流动性和汇率风险。

不强调点预测收益。

### 3–5 年

结合：

- 当前估值；
- 股息和利息；
- 盈利增长；
- 部分估值回归；
- 汇率情景；
- 持续入金。

### 5–10 年

展示长期复合收益中枢和宽可信区间，并明确结构变化风险。

## 3. 预测组成

```text
Expected total return =
  income yield
  + fundamental growth
  + valuation change
  + FX contribution
  - fees/costs/taxes
```

Value、Trend 和 Macro 的作用要区分：价值更多影响长期中枢，趋势更多影响当前风险暴露。

## 4. 可信区间

建议同时展示：

- 参数不确定性；
- 历史残差不确定性；
- 模型之间差异；
- 数据质量；
- 情景假设。

不能把简单历史分位称为严格统计置信区间。UI 使用“模型区间”或“情景区间”更准确。

## 5. Monte Carlo

逐步实现：

1. 历史块 Bootstrap；
2. 多元正态/Student-t 基线；
3. Regime-switching；
4. 保留尾部与相关性结构的 Copula 或情景生成；
5. 现金流、汇率和再平衡规则联合模拟。

每种方法必须有适用范围和失败模式说明。

## 6. 压力测试

预定义场景：

- A 股下跌 20%；
- 港股下跌 30%；
- 美股科技下跌 35%；
- 全球股票相关性升至 0.8；
- 股票与债券同时下跌；
- CNY 对 USD 升值或贬值 10%；
- BTC 下跌 60%；
- 新增资金暂停 12 个月；
- 交易成本翻倍；
- 数据和执行延迟。

输出：组合损失、风险贡献、触发动作、现金变化和恢复路径。

## 7. 财富路径

输入：

- 初始资本；
- 定期和不定期入金；
- 收入增长或中断；
- 目标资产配置；
- 税费；
- 目标金额和时间。

输出：

- 期末财富分布；
- 达成目标概率；
- 达成时间分布；
- 本金与投资收益贡献；
- TWR 与 XIRR 分布；
- 最大回撤和恢复期。

## 8. 反事实模拟

对每次真实决策计算：

- 执行建议；
- 不执行；
- 延迟执行；
- 固定基准；
- 不同现金部署比例。

反事实只用于归因，不作为证明策略正确的唯一依据。

## 9. 模型风险

模拟结果必须包含：

- 方法名称和版本；
- 数据区间；
- 参数；
- 随机种子；
- 适用限制；
- 是否包含极端事件；
- 是否考虑汇率、成本和现金流。

## 10. 首版验收

- 固定压力场景可复现；
- 历史块 Bootstrap 可运行；
- 持续入金财富路径支持；
- 输出区间而非点值；
- UI 明确标记假设与非保证性质。
