# ADR-0002：现金作为一级可投资资产

- 状态：Accepted
- 日期：2026-08-05

## 背景

降低某指数仓位不应强制增加其他风险资产。系统还需要支持初始未完全部署、持续入金和多币种现金。

## 决策

现金以正式 Instrument 进入 Universe，具有币种、收益率、权重上下限和风险作用。所有权重含现金且总和为 1。

## 结果

- 目标权重不再“必须投满风险资产”；
- 减仓可自然流向现金；
- 新增资金先进入现金池；
- 可拆分 CNY/USD/HKD；
- 需要明确现金收益和汇率风险。

## 负面影响

现金配置会产生机会成本，且初始部署期可能违反正常现金上限，因此必须引入阶段状态和独立约束。
